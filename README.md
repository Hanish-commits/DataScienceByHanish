# Python Foundations & Data Science

A hands-on record of my journey from Python fundamentals toward data science. This repository brings together notes, cheat sheets, examples, and practice code.

## Learning path

| Topic | What I’m practicing |
|---|---|
| **01 · Fundamentals** | Core Python concepts and syntax |
| **02 · Working With Data** | Data structures and everyday data tasks |
| **03 · Loops & Patterns** | Iteration and pattern-building exercises |
| **03 · Conditionals** | Decisions, comparisons, and branching |
| **04 · Functions** | Reusable code and problem-solving |
| **05 · Object-Oriented Programming** | Classes, objects, and OOP concepts |
| **06 · Exception Handling** | Handling errors and writing reliable programs |
| **07 · Modules & Imports** | Organizing code and using modules |
| **08 · File Handling** | Reading and writing files |
| **09 · Comprehensions** | Concise ways to build collections |
| **10 · Iterators & Generators** | Lazy iteration and generator patterns |
| **11 · Packages & Virtual Environments** | Installing packages and managing environments |

## How to use this repository

1. Start with the fundamentals and work through the topics.
2. Read the notes and cheat sheets.
3. Run the examples and experiment with them.
4. Practice by writing small programs of your own.
